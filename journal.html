    Weekly review

    —

      A review is short on purpose: read the breakdowns, tick what you actually did, answer the four questions and pick one change for next week. Ten minutes every Friday compounds faster than any indicator.

      Export & import

      JSON keeps everything (entries and weekly reviews) and re-imports exactly. CSV opens in a spreadsheet; one row per entry.
      Merging keeps your current entries and updates any with the same id when the import is newer. Replace wipes this device's journal first, so export it before you do.

      Edit entry

      Name the pattern you were trading. Grouping by setup is how you find out which ideas have an edge.
      Short labels you can filter by later: timeframe, rule-following, exit quality.
      How did you feel when you clicked the button? Be honest; this column is usually the most revealing one in the breakdown.
      1 = a coin flip, 5 = textbook setup. Compare it with the result over time: are your confident trades actually better?
      Rate the decision, not the result. A planned trade that hit its stop can be a 5; a lucky impulse can be a 1.
